# 🎵 Spotify Clone

This is a frontend project that replicates the UI and basic functionality of Spotify using HTML, CSS, and JavaScript. It includes responsive design, music cards, a playback bar, and sections like Trending, Recently Played, and Popular Artists.

## 🚀 Features

- Responsive Spotify-like UI
- Custom playback controls (Play, Pause, Next, Previous)
- Sections for:
  - 🎧 Trending Now
  - 🔥 Popular Artists
  - ⏪ Recently Played
- Smooth user interface with modern styling
- Hover effects and transitions for interactivity

## 🛠️ Built With

- **HTML5** – Markup structure
- **CSS3** – Styling and layout
- **JavaScript** – Playback logic and interaction
